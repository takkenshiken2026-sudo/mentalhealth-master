問題編：職場環境・配慮

第4問

職業性ストレス簡易調査票を用いた「仕事のストレス判定図」に関する次のア〜エの記述について、正しいもの（○）と誤っているもの（×）の組み合わせとして、最も適切なものを一つ選びなさい。

  1. ア 仕事のストレス判定図は、「量－コントロール判定図」と「職場の支援判定図」からなる。
  2. イ 全国平均を100とした健康リスクによって、集団のストレスの程度を比較できる。
  3. ウ 個人のストレス状態を診断し、高ストレス者を選定するために用いる。
  4. エ 判定図を作成するには、職業性ストレス簡易調査票の57項目すべての回答結果が必要である。
  1. ① ア○　イ○　ウ×　エ×
  2. ② ア×　イ○　ウ×　エ○
  3. ③ ア○　イ×　ウ○　エ×
  4. ④ ア○　イ○　ウ○　エ×

解答欄（　　　）

第17問

職場のストレス要因に関する次の記述のうち、最も不適切なものを一つ選びなさい。

  1. ① 仕事の量的負担だけがストレス要因となり、仕事の質的負担（難しさや責任の重さ）はストレス要因にならない。
  2. ② 役割の曖昧さや役割葛藤は、職場の代表的なストレス要因とされる。
  3. ③ 交替勤務や深夜業は生活リズムを乱しやすく、睡眠の質の低下などを通じて労働者の心身に大きな負担となりうる。
  4. ④ 職場の対人関係の問題は、強いストレスとなっている事柄の上位に挙げられている。

解答欄（　　　）

第18問

ラインによる職場環境改善の進め方として、最も適切なものを一つ選びなさい。

  1. ① 職場環境改善は、集団分析で高ストレスと判定された職場だけで行えばよく、それ以外の職場では必要ない。
  2. ② 改善の効果を早く出すため、多くの対策を一度にまとめて導入することが望ましい。
  3. ③ 改善計画は、労働者に負担をかけないよう、職場での話し合いを行わずに管理監督者が単独で立てる。
  4. ④ 集団分析の結果を活用して職場のストレス状況を把握し、部下の意見も聞きながら改善策を検討する。

解答欄（　　　）

第19問

職場環境改善の評価に関する記述として、最も適切なものを一つ選びなさい。

  1. ① 改善策の実施状況などのプロセス評価と、ストレス反応や欠勤率の変化などのアウトカム評価を組み合わせて評価する。
  2. ② 改善の効果がみられなかった場合でも、計画どおりに実施した以上は、改善策や計画の内容をあらためて見直す必要はない。
  3. ③ 職場環境改善の効果は、改善策を実施した直後に一度だけ評価すれば十分である。
  4. ④ 集団分析の結果を評価に用いる場合は、改善前の結果と比較せず、改善後の結果だけで判断する。

解答欄（　　　）

第20問

部下のメンタルヘルス不調のサインとして、最も不適切なものを一つ選びなさい。

  1. ① 以前に比べて遅刻や早退、欠勤が増えた。
  2. ② 仕事の能率が落ち、ミスや事故が増えた。
  3. ③ 新しい仕事を任され、一時的に上司への質問の回数が増えた。
  4. ④ 報告や相談が減り、以前に比べて職場での口数が少なくなった。

解答欄（　　　）

第21問

管理監督者が注意すべきストレス要因に関する記述として、最も適切なものを一つ選びなさい。

  1. ① 昇進や昇格のように本人にとって望ましい出来事であっても、責任や役割の変化によってストレス要因となることがある。
  2. ② 異動や転勤によるストレスは、本人が希望した異動であれば生じることはない。
  3. ③ 家庭の問題などの職場外の要因は仕事のストレスとは別のものであり、職場でのメンタルヘルス不調に影響することはない。
  4. ④ 単身赴任は、家族と離れて仕事に集中できるため、ストレス要因とはならないとされる。

解答欄（　　　）

第22問

管理監督者による過重労働防止の対応として、最も適切なものを一つ選びなさい。

  1. ① 部下の労働時間の把握は、本人の自己申告のみによることが原則とされている。
  2. ② 時間外労働の多い部下がいても、本人が「大丈夫」と言っていれば、業務量を調整する必要はない。
  3. ③ 業務量の偏りを把握し、必要に応じて業務分担や業務の進め方を見直す。
  4. ④ 長時間労働の削減は、職場全体の業務量を変えずに、個々の部下の努力によって達成することが基本である。

解答欄（　　　）

第23問

社会的支援（ソーシャルサポート）の種類に関する次のア〜エの記述について、正しいもの（○）と誤っているもの（×）の組み合わせとして、最も適切なものを一つ選びなさい。

  1. ア 情緒的サポートとは、共感したり話を聴いたりして、気持ちを受け止めることである。
  2. イ 情報的サポートとは、問題解決に役立つ情報や助言を提供することである。
  3. ウ 道具的サポートとは、仕事ぶりを評価してフィードバックすることである。
  4. エ 評価的サポートとは、業務の一部を代わりに行うなど、具体的な手助けをすることである。
  1. ① ア○　イ○　ウ×　エ×
  2. ② ア○　イ×　ウ○　エ×
  3. ③ ア×　イ○　ウ×　エ○
  4. ④ ア○　イ○　ウ○　エ×

解答欄（　　　）

第24問

部下のメンタルヘルスに関する個人情報の取り扱いとして、最も適切なものを一つ選びなさい。

  1. ① 部下から相談を受けた健康情報を人事部門に伝える場合、本人の同意を得る必要はない。
  2. ② 部下の健康情報は、本人の同意を得たうえで、支援に必要な範囲の情報にとどめて関係者間で共有する。
  3. ③ メンタルヘルスに関する情報は要配慮個人情報にあたるため、本人の同意があっても、産業保健スタッフと共有することはできない。
  4. ④ 産業医が面談で得た情報は、事業者が就業上の措置を判断するため、すべてそのまま管理監督者に伝えられる。

解答欄（　　　）

第25問

管理監督者自身のメンタルヘルスケアとして、最も不適切なものを一つ選びなさい。

  1. ① 管理監督者は部下のケアを担う立場であるため、自らのストレスについて産業保健スタッフに相談することは控える。
  2. ② 管理監督者は、昇進や部下の増加、上司と部下の板挟みなどによる役割の変化がストレス要因となりやすいことを理解しておく。
  3. ③ 管理監督者も、自らのストレスに気づいて対処するセルフケアに取り組むことが重要である。
  4. ④ 管理監督者の長時間労働も健康障害の原因となるため、事業者は管理監督者の労働時間の状況も把握する。

仕事の質的負担もストレス要因となるため、量的負担だけとする（1）が最も不適切。

第18問　正解 ④

集団分析の結果を活用して状況を把握し、部下の意見も聞きながら改善策を検討することが適切なため（4）が正解。

第19問　正解 ①

プロセス評価とアウトカム評価を組み合わせて評価することが適切なため（1）が正解。

第20問　正解 ③

新しい仕事に伴う一時的な質問の増加は自然な反応で、それだけでは不調のサインとはいえないため（3）が最も不適切。

第21問　正解 ①

昇進や昇格のような望ましい出来事でも、責任や役割の変化によってストレス要因となることがあるため（1）が適切。

第22問　正解 ③

アとイは正しく、仕事ぶりの評価は評価的サポート（ウ×）、具体的な手助けは道具的サポート（エ×）であるため（1）が適切。
