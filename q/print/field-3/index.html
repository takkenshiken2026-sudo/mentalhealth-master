問題編：相談・連携・復職

第5問

部下から「死にたい」という言葉が出たとき、管理監督者の対応として最も適切なものを一つ選びなさい。

  1. ① 本人のプライバシーを守るため、家族や産業医には知らせず、管理監督者だけで対応する。
  2. ② 深刻に受け止め、一人にせず、速やかに産業医や専門家につなぐ。
  3. ③ まずは本人の気が済むまで話を聞き、専門家への紹介は本人が希望してから行う。
  4. ④ 「本気なのか」と尋ねると追い詰めるため、その話題には触れずに様子を見る。

第6問

「心の健康問題により休業した労働者の職場復帰支援の手引き」に示された職場復帰支援の流れに関する次のア〜エの記述について、正しいもの（○）と誤っているもの（×）の組み合わせとして、最も適切なものを一つ選びなさい。

  1. ア 第1ステップでは、病気休業の開始と休業中のケアを行う。
  2. イ 第2ステップでは、主治医による職場復帰可能の判断が示される。
  3. ウ 第3ステップでは、事業者による最終的な職場復帰の決定を行う。
  4. エ 職場復帰支援プランは、第5ステップの職場復帰後のフォローアップの段階で初めて作成する。

解答欄（　　　）

第26問

管理監督者が部下の相談を受ける際の基本姿勢として、最も適切なものを一つ選びなさい。

  1. ① 業務に直接関係のない家庭の悩みについては、管理監督者が聴く必要はない。
  2. ② 相談を受けた内容は、本人の了解の有無にかかわらず、すべて人事部門に報告しなければならない。
  3. ③ まず話を十分に聴き、部下が自分の気持ちや状況を話せる場をつくることを優先する。
  4. ④ 部下を早く楽にさせるため、話の途中でも、すぐに解決策を示すことを優先する。

解答欄（　　　）

第27問

メンタルヘルス不調の発見に関する記述として、最も適切なものを一つ選びなさい。

  1. ① 本人に自覚がない場合や、周囲に知られたくないと隠す場合があり、発見が遅れやすい。
  2. ② メンタルヘルス不調は本人が必ず自覚しているため、本人からの申告を待てば発見できる。
  3. ③ うつ病は初期から必ず気分の落ち込みとして現れるため、身体の不調との区別は容易である。
  4. ④ 定期健康診断の問診を行えば、メンタルヘルス不調はほぼ確実に発見できる。

解答欄（　　　）

第28問

管理監督者が部下の話を聴く意義として、最も適切なものを一つ選びなさい。

  1. ① 日頃から話を聴くことで、早期に不調に気づき、適切な支援につなげることができる。
  2. ② 管理監督者が話を聴く目的は、部下の病名を見極め、治療の方針を判断することにある。
  3. ③ 管理監督者には、カウンセラーと同様に、専門的な心理療法を行うことが求められる。
  4. ④ 部下の話を聴くことは、業務上の問題が生じた部下に限って行えばよい。

解答欄（　　　）

第29問

不調が疑われる部下との面談における傾聴の方法として、最も不適切なものを一つ選びなさい。

  1. ① 相手のペースに合わせ、結論を急がせない。
  2. ② 相手が沈黙しても、すぐに話を促さずに待つ。
  3. ③ 相手の感情や言葉を繰り返したり言い換えたりして、理解しようとする姿勢を示す。
  4. ④ 「私も同じ経験をしたが乗り越えた」と、自分の経験を話して励ます。

解答欄（　　　）

第30問

部下を専門家へ紹介する際の対応として、最も適切なものを一つ選びなさい。

  1. ① 産業医や保健師などに事前に相談したうえで、受診の勧め方を検討する。
  2. ② 本人が受診を拒否した場合は、懲戒処分を示して受診させることが管理監督者の責任である。
  3. ③ 精神科の受診を勧めると本人を傷つけるため、内科の受診だけを勧めるべきである。
  4. ④ 専門家への紹介は、本人の状態が明らかに悪化し、欠勤が続くようになってから行う。

解答欄（　　　）

第31問

産業医に関する次の記述のうち、最も適切なものを一つ選びなさい。

  1. ① 産業医は常時50人以上の労働者を使用する事業場で選任が義務づけられ、常時500人以上の事業場では、業務の種類にかかわらず専属の産業医を選任しなければならない。
  2. ② 産業医は衛生委員会の委員とはならず、求めに応じて意見を述べるにとどまる。
  3. ③ 産業医は、少なくとも年1回、作業場等を巡視しなければならない。
  4. ④ 産業医は、労働者の健康を確保するため必要があると認めるときは、事業者に対し、労働者の健康管理等について必要な勧告をすることができる。

解答欄（　　　）

第32問

事業場外の支援機関に関する次のア〜エの記述について、正しいもの（○）と誤っているもの（×）の組み合わせとして、最も適切なものを一つ選びなさい。

  1. ア 地域産業保健センターは、主に労働者数50人未満の小規模事業場を対象に、健康相談などを無料で行っている。
  2. イ 産業保健総合支援センターは、各都道府県に設置され、産業保健スタッフに対する研修や専門的な相談に応じている。
  3. ウ 精神保健福祉センターは、都道府県や政令指定都市に設置され、心の健康に関する相談に応じている。
  4. エ 産業保健総合支援センターは、労働者数1,000人以上の大規模事業場のみを対象としている。
  1. ① ア○　イ○　ウ○　エ×
  2. ② ア○　イ×　ウ○　エ×
  3. ③ ア×　イ○　ウ○　エ×
  4. ④ ア○　イ○　ウ×　エ○

解答欄（　　　）

第33問

医療機関の種類と選び方に関する記述として、最も適切なものを一つ選びなさい。

  1. ① 心療内科は、主に統合失調症などの精神疾患の入院治療を専門とする診療科である。
  2. ② 精神科を受診するには、必ず事業者が発行する紹介状が必要である。
  3. ③ 精神科は、うつ病や統合失調症など、精神疾患を幅広く診療の対象とする。
  4. ④ 心身症は精神科だけが診療する病気であり、心療内科では扱わない。
