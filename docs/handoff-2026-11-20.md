## 2. ビルド・デプロイの仕組み（重要）

**静的ページ（q/配下）は手編集しない。** 元データ(CSV)＋ジェネレータ(tools/)から再生成する。

### 再生成コマンド（q/ 配下を作り直す）
```bash
python3 tools/build_past_question_pages.py
python3 tools/build_practice_ichimon_pages.py
python3 tools/inject_adsense_head.py
python3 tools/build_pwa.py
python3 tools/normalize_article_links.py --apply
bash tools/prepare_public_site.sh   # public_site/ へ同期
```

### 主なジェネレータ
- `tools/q_explanation.py` … 解説HTMLの組み立て（正解の理由/他の選択肢/一問一答解説）
- `tools/q_similar_questions.py` … 「類似の問題」
- `tools/q_nav_cta.py` … 連番ナビ＋「解く」CTA
- `tools/q_page_seo.py` … 学習導線の定型文など
- `tools/build_past_question_pages.py` / `tools/build_practice_ichimon_pages.py` … ページ本体テンプレート
- `index.html` … SPA本体（site-only。ビルドで上書きされない正本）

### 本番公開（デプロイ）
1. 開発ブランチへコミット・プッシュ
2. `git push origin claude/jolly-johnson-isgngp:main`（fast-forward）
3. Actions `deploy-pages.yml`（`tools/build_site.py` → `public_site` を GitHub Pages へ）
4. 確認: `mcp__github__actions_list` / `actions_get`（run の conclusion=success）

> 注意: `tools/apply_site_config.py` を単独実行すると index.html 等にビルド順序由来の
> 無関係差分（PWAヘッド位置・リンク正規化の揺れ）が出る。通常は `build_all.py` の
> 一連で是正されるが、部分実行時は `git restore --source=HEAD` で不要差分を除くこと。

## 4. 元データ監査の結果（未対応・要判断） ★引き継ぎの主題

`data/*.csv` を分析して判明した「変更すべき箇所」。重要度順。

### 最重要（事業・信頼性）
1. **「過去問」が実際の過去問ではない**
   - `past_questions.csv` は全300件が `exam_year=2026`、`exam_wareki=演習`（年号でなく「演習」の文字）。
   - 実際の過去問の再現ではなく演習問題を「過去問」として掲示。サイト導線「過去問を解く」と実態が不一致。
   - 判断事項: 表記を「演習/オリジナル問題」に改める、実際の過去問を用意する、等。
2. **過去問300問 ≒ 実践演習300問が実質同一**
   - 問題文一致300組（うち152完全一致＋148は選択肢の言い換え）、解説本文も一致。実践固有はテレワーク8問(301–308)のみ。
   - コンテンツの水増し。差別化 or 統合の判断。

### 構造的（学習価値・分野別SEO）
3. **カテゴリが3分類のみ（本来は7領域）**
   - 3セットとも `category` は「基礎・役割／職場環境・配慮／相談・連携・復職」の3種。
   - II種公式の出題範囲は7領域（I意義と役割/IIストレス基礎知識/III職場環境の評価改善/IV個々への配慮/V相談対応/VI社内外連携/VII復職支援）。
   - 3集約では本番の領域別対策とズレる。`category` の7領域再分類を推奨。

### データ整備（メタデータ）
4. **過去問に `tags` 列が無い**（実践・一問一答にはある）→ 「類似の問題」判定・絞り込み精度が過去問だけ低い。
5. **一問一答の `explanation_correct`/`explanation_opposite`/`explanation_point`/`note` が全1200件空**（`explanation` のみ使用）。現状はジェネレータの推論補完。元データ整備の余地。
6. **実践の `explanation_choices` が8件空**。

### 品質（任意）
7. **誤答肢の約14%（129/900）が「一切」「のみ」「すべて」「必ず」等の極端表現** → 定型的で正解を推測しやすい。
8. **一問一答に水増し的な近似重複** 例: 「過労死等防止啓発月間は{1月/6月/11月/3月}である」4問（正答11月のみ）。意図的な数値バリエーションだが冗長。

### カテゴリ別件数（参考）
