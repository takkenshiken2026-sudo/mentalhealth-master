# 問題の難易度（レベル）の付け方

対象: II種の実践演習 310問（過去問1〜300は実践演習1〜300と同じ問題のため共通）と一問一答 1,200問。
正本: `data/question_levels.csv`（列: `kind`, `id`, `level`, `basis`）。
サイトの難易度の★（1〜5）と、実力診断テストの出題に使う。

## 判定の考え方
「管理監督者として公式テキストを一通り読んだ受験者が、正しく判断するのにどれだけ正確な知識が要るか」で決める。
問題文の長さや分野ではなく、**正答にたどり着くために必要な知識の細かさと、紛らわしさ**で判定する。

| レベル | 目安 | 典型 |
|---|---|---|
| 1 | 常識や一般的な理解で判断できる | 誤りの記述が「一切」「必ず」「すべて」など極端で明らか |
| 2 | テキストの基本事項を知っていれば解ける | 頻出の用語の意味、基本原則（4つのケア、安全配慮義務の存在など） |
| 3 | 制度・手順の内容を正確に理解している必要がある | 主体（誰が）・目的・順序の区別。紛らわしい選択肢が1つある |
| 4 | 細かい知識、または複数の知識の比較が必要 | 数値・期間・回数・条文・調査結果、似た制度の比較、全選択肢の正誤判断が要る否定形 |
| 5 | 細かい知識を複数組み合わせる、または例外・事例の総合判断 | 正誤の組合せ問題で細かい知識が複数要る、例外規定、事例で複数要素を判断 |

一問一答（○×）は、1つの記述について同じ基準で判定する（誤りの箇所が数値・主体の入れ替えなど細かいほど高い）。

## 根拠の記号（basis 列）
| 記号 | 意味 |
|---|---|
| 常 | 常識・極端な表現で判断できる |
| 基 | 基本用語・基本原則 |
| 制 | 制度・手順の内容理解 |
| 主 | 主体・対象の区別（誰が・誰に） |
| 順 | 順序・段階の区別 |
| 数 | 数値・期間・回数・割合 |
| 法 | 条文・法令・指針の細部 |
| 比 | 似た概念・制度の比較 |
| 否 | 「適切でないもの」で全選択肢の判断が必要 |
| 組 | 正誤の組合せ（ア〜エ） |
| 事 | 事例の判断 |
| 例 | 例外規定 |

## 注意
- レベルは担当者の判定で、受験者の正答率の実績ではない。実力診断テストの結果がたまったら、実際の正答率で見直す。
- 問題を作り直したときは、その問題のレベルも見直す。
