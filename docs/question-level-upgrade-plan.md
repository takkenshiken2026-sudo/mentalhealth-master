# II種 問題の難易度引き上げ（2026年11月〜）

## 目的
易しい問題（レベル1・2）が多いと「このままで大丈夫」という安心感を与え、予想模試の購入につながりにくい。
レベル1・2の比率を下げ、3〜5を増やす。ただし**正確さを最優先**し、不当な引っかけや出題範囲外の知識で難しくしない。

レベルの判定基準: [question-difficulty-rubric.md](./question-difficulty-rubric.md)（正本 `data/question_levels.csv`）

## 現状と目標（4択＝実践演習・過去問 310問）

| レベル | 現状 | 目標 |
|---|---|---|
| 1 | 90（29%） | 0 |
| 2 | 92（30%） | 約45（15%） |
| 3 | 69（22%） | 約120（40%） |
| 4 | 48（15%） | 約100（30%） |
| 5 | 11（4%） | 約45（15%） |

一問一答（1,200問）は、対応する4択の作り直しに連動して上がる。4択がすでにレベル3以上のグループでも、レベル1の記述は個別に作り直す。
目標: レベル1は1割以下、レベル2は3割以下。

## 難しくする方法（使ってよいもの）
1. **誤りは1か所だけ入れ替える**: 正しい記述のうち、主体（誰が）・数値・期間・順序・対象範囲・例外の1点だけを誤りにする。
2. **極端な語で見抜ける誤りを作らない**: 「一切」「必ず」「すべて」「のみ」などで誤りと分かる選択肢は使わない（正しい記述として使う場合は可）。
3. **似た概念との入れ替え**: 情緒的⇔情報的サポート、一次⇔二次予防、第3⇔第4ステップ、主治医⇔産業医⇔事業者 など。
4. **事例問題は「どれももっともらしい」形に**: 明らかに不適切な対応を並べず、指針・手引きの手順や本人同意の要否などで差がつく選択肢にする。
5. **形式の追加**: 正誤の組合せ（ア〜エ）、「適切でないもの」を一部で使う（全体の3〜4割まで）。

## 使わないもの
- 出題範囲（公式テキスト第6版の7領域）を外れる知識
- 複数の解釈ができる文、日本語の読みにくさで難しくすること
- 確認できない数値・統計・最新改正（一次資料で確認できないものは使わない）

## 正確さの担保
- 法令・指針・手引き・統計は、一次資料（e-Gov法令検索、厚生労働省の指針・手引き・調査結果）で確認したものだけを使う。各回の原稿に出典を書く。
- 解説（explanation・要約・正解の理由・誤肢・一問一答解説）は、変えたすべての論点を説明する。
- 正答番号は原則維持（選択肢位置の偏りは調整済みのため）。
- 機械検査: `tools/check_revision_quality.py`（最長選択肢が正答でない・組合せの形式・一問一答4件の○×が全部同じでない）、`tools/apply_question_revisions.py --dry-run`、`--check`。
- 作り直した問題は判定基準で再判定し、`data/question_levels.csv` を更新する。

## 進め方（1回＝約20問）
1. 対象を選ぶ（分野ごと、レベル1から）
2. 原稿を書く: `data/revisions/src/line_upgrade_<分野>_bN.txt`（書式は `tools/revision_text_to_json.py`）
3. JSON に変換 → 機械検査 → 自己点検（出典との照合、紛らわしさが「知識で解ける」範囲か）
4. 反映（`apply_question_revisions.py`）→ ビルド → 表示確認
5. 改訂記録（`reports/revisions/`）を出力してコミット
6. 第1回（試行）は運営の確認を受けてから、残りを進める
