メンタルヘルス・マネジメント検定II種の試験当日の持ち物

メンタルヘルス・マネジメント検定II種（ラインケア）の試験当日は、持ち物の不備が受付遅延·失格の原因になります。たとえば10月12日（日）10:00開始·100問120分の回なら、10月11日21:00までに持ち物7点をそろえ、10月12日7:00に最終確認する逆算が定番です。本記事では持ち物チェックを表にまとめ、当日の流れはexam-day-flow·注意点はexam-day-guideと役割分担します。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の受験要項·受験票です。

この記事の要点

本記事を読むと、たとえば10月11日21:00に受験票·身分証·黒または青の筆記用具·非電子式時計をカバンに入れ、9:00会場到着に間に合う準備が完了できます。

  • 持ち物7点
  • 前日21:00
  • 100問120分
  • 受験票正本
  • guide連携

1持ち物チェックの全体像（前日まで）

II種ラインケアの持ち物は、日産協の公開試験 受験要項·受験票が正本です。100問·四択一·120分·70点以上の試験形式は変わりませんが、会場ごとに禁止物品の指示が異なる場合があります。

| 区分 | 内容 |
| --- | --- |
| 必須 | 受験票·身分証 |
| 筆記 | 黒または青の鉛筆·ボールペン |
| 補助 | 非電子式時計·消しゴム |
| 禁止 | 要項·会場指示どおり |

  • たとえば10月12日（日）10:00開始なら
  • 10月11日21:00に持ち物をカバンへ入れ
  • 10月12日7:00に受験票の氏名·会場·開始時刻を最終確認してください

I種（105点＋論述25点）や衛生管理者30問180点とは別試験です。

2必須7点の持ち物リスト

申込時の氏名表記と身分証の不一致は受付で止まる典型例です。次の7点を前日21:00までにそろえます。

| # | 持ち物 | 確認 |
| --- | --- | --- |
| 1 | 受験票 | 氏名·会場·10:00開始 |
| 2 | 身分証 | 申込表記と一致 |
| 3 | 鉛筆·ボールペン | 黒または青 |
| 4 | 消しゴム | マーク修正用 |
| 5 | 非電子式時計 | 120分管理 |
| 6 | 水分 | 要項·会場指示 |
| 7 | 体温計等 | 体調不良時の判断 |

例えば10月11日21:00に7点をテーブル横に並べ、10月12日7:00にカバン内を再点検するリマインダーを設定します。スマートフォンは電源OFF·監督者指示の場所へ保管が原則です。

3筆記用具とマークシートの注意

100問·四択一の答案はマークシート方式です。鉛筆·ボールペンの色·太さは要項が正本ですが、黒または青が無難な選択肢です。

| 項目 | 注意 |
| --- | --- |
| 色 | 黒または青 |
| 消しゴム | マーク完全消去 |
| 修正液 | 原則禁止 |
| 予備 | 2本以上持参 |

たとえば演習100問の模擬マークで3問分の塗り直しを10月10日に練習すると、本番12:00終了前の見直し15分で迷い問題5問の修正がスムーズになります。70点（70問正解）確保のため、マークミス防止は持ち物準備とセットです。

4exam-day-guide/exam-day-flowとの分担

  • 本記事は「持ち物7点のチェックリスト」
  • exam-day-guideは「時間配分·70点戦略」
  • exam-day-flowは「9:00到着〜12:00退場の流れ」に特化してい

| 記事 | 役割 |
| --- | --- |
| exam-day-items（本記事） | 持ち物7点 |
| exam-day-guide | 時間配分·70点 |
| exam-day-flow | 到着〜退場 |

  • 例えば試験1週前にexam-last-minuteで弱点確認
  • 10月11日21:00に本記事で持ち物準備
  • 10月12日7:00にexam-day-flowのタイムライン（9:00到着等）を見直す流れが定番

5前日〜当日朝の持ち物リハーサル

持ち物は「そろえたつもり」が当日朝の混乱で抜けがちです。前日21:00と当日7:00の2回点検を習慣化します。

1. 10月11日21:00：7点をカバンに入れ、受験票を最上段に
2. 10月11日22:00就寝：120分集中のため7時間以上睡眠
3. 10月12日7:00：カバン内7点の再点検
4. 10月12日8:00：朝食·水分補給
5. 10月12日8:30：出発（10:00開始·通勤30分想定）

  • たとえば8:30出発·9:00到着·9:30受付完了なら
  • 9:30〜10:00の30分間でトイレ·深呼吸を済ませ
  • 100問120分の本番に備え

6よくある質問

試験前日に何時までに持ち物をそろえればよいですか？
前日21:00までが定番です。たとえば10月12日（日）10:00開始なら、10月11日21:00に受験票·身分証·筆記用具·非電子式時計をカバンに入れ、10月12日7:00に最終確認してください。持ち物の正本は受験要項·受験票です。当日の流れはexam-day-flowのタイムライン節で確認します。
スマートフォンは持ち込めますか？
会場·試験回の要項·監督者指示が正本です。多くの回では電源OFF·指定場所への保管が求められます。例えば9:15受付完了後にスマートフォンを預け、12:00終了·12:15退場後に受け取る流れが一般的です。時計機能は非電子式時計で120分を管理してください。
持ち物と当日の流れはどこで確認しますか？
持ち物7点は本記事、9:00到着〜12:00退場の流れはexam-day-flow、時間配分·70点戦略はexam-day-guideがそれぞれの正本です。たとえば10月11日21:00に本記事·10月12日7:00にexam-day-flowの順で読むと漏れが減ります。105点＋論述25点はI種の基準であり、II種とは異なります。
