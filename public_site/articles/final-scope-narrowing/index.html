メンタルヘルス・マネジメント検定II種の直前の範囲絞り込み

メンタルヘルス・マネジメント検定II種（ラインケア）の直前期は、7領域すべてを均等に復習するより弱点3領域に絞るのが定番です。たとえば10月12日（日）10:00開始·100問120分なら、10月5日（日）に7領域の正答率を棚卸しし、55％未満3領域に用語30語＋演習60問を集中する逆算が目安です。本記事では70点＝70問正解の絞り込み表をまとめ、1週間計画はfinal-week-prep·exam-last-minuteと役割分担します。

この記事の要点

本記事を読むと、たとえば演習100問中72問正解でも「相談対応」「個別配慮」「推進」の3領域が55％未満ならどの領域から20問ずつ解き直すべきかが分かり、100問120分で70点を確保する直前の優先順位が立てられます。

  • 7領域
  • 弱点3領域
  • 70点70問
  • 55％基準
  • week-prep連携

1直前の範囲絞り込みの全体像

II種ラインケアの直前期は100問·70点以上が前提です。7領域すべてを新規暗記するより、弱点3領域に絞るのが得点維持に有効です。

| 方針 | 内容 |
| --- | --- |
| 棚卸し | 7領域正答率 |
| 絞込 | 55％未満3領域 |
| 目標 | 70問正解 |
| 禁止 | 新参考書追加 |

たとえば10月5日（日）に7領域の正答率を記録し、55％未満3領域に10月6〜10日の復習を集中させる流れが定番です。I種105+論述25点の範囲絞り込みと混同しないでください。

27領域の正答率棚卸し表

直前2週間の演習結果から7領域の正答率を1枚にまとめます。100問中の領域別出題数はおおむね均等です。

| 領域例 | 直前の目安 |
| --- | --- |
| 意義·法令 | 60％以上 |
| 相談対応 | 弱点なら集中 |
| 個別配慮 | 線引き表 |
| 推進 | 主体分担 |

例えば10月5日時点で演習200問の記録から正答率55％未満が3領域あれば、それ以外4領域は誤答ノート確認のみに時間を短縮する流れが定番です。

3弱点3領域の優先順位づけ

55％未満の領域が3つ以上ある場合、正答率が最も低い3領域に絞ります。

| 優先 | 基準 |
| --- | --- |
| 1位 | 正答率最低 |
| 2位 | 出題頻度高 |
| 3位 | 誤答パターン多 |
| 除外 | 60％以上4領域 |

たとえば「相談対応」50％·「個別配慮」52％·「推進」54％なら、この3領域に10月6〜8日で用語30語＋演習60問を割り当てる逆算が定番です。

470点＝70問正解の捨て基準

合格基準は100点満点中70点以上、すなわち70問以上の正解です。直前は「全部完璧」より70問確保に絞ります。

| 判断 | 基準 |
| --- | --- |
| 捨て | 3回以上誤答 |
| 要確認 | 1〜2回誤答 |
| 確保 | 正答率70％以上 |
| 見直し | 15分確保 |

例えば10月7日模試72問正解（72点）なら合格圏内ですが、捨て基準を決めずに全問見直すと11:55に75問しか到達しない典型例があります。

5final-week-prep/exam-last-minuteとの分担

直前の範囲絞り込みに関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| final-scope-narrowing（本記事） | 7領域·弱点3 |
| final-week-prep | 1週間スケジュール |
| exam-last-minute | 1週間チェックリスト |

  • たとえば10月5日に本記事で弱点3領域を確定
  • 同日にfinal-week-prepの日別表に組み込み
  • 10月11日21:00にexam-last-minuteで最終確認する流れが定番

6よくある質問

直前は何領域に絞るべきですか？
55％未満の弱点3領域に絞るのが定番です。たとえば10月5日に7領域の正答率を棚卸し、55％未満3領域に用語30語＋演習60問を10月6〜10日に集中させてください。60％以上の4領域は誤答ノート確認のみで時間を短縮します。70点（70問正解）確保が直前の最低ラインです。
70点と70問正解の関係は？
II種ラインケアは100問·四択一で、70点以上＝70問以上の正解です。例えば10月7日模試68問正解（68点）なら不合格圏内のため、弱点3領域から10月8〜9日に20問ずつ解き直し、70問正解を目指してください。105点＋論述25点はI種の基準であり、II種とは異なります。
範囲絞り込みと1週間計画はどう使い分けますか？
final-scope-narrowing（本記事）は7領域·弱点3領域の絞り込み基準、final-week-prepは10月5〜11日の日別スケジュール表、exam-last-minuteは1週間チェックリストに特化しています。たとえば10月5日に本記事で弱点3領域確定、同日にfinal-week-prepの表へ組み込む順が定番です。
