メンタルヘルス・マネジメント検定II種の類似資格との比較｜I種·III種·衛生管理者との違い

メンタルヘルス・マネジメント検定II種（ラインケア）の類似資格との比較は、100問·120分·70点以上のII種を基準にI種·III種·衛生管理者試験との形式·合格基準·受験目的の違いを整理する正本です。受験資格詳細はexam-eligibility記事、併願ルールはconcurrent-exam-rulesと役割分担します。たとえば6月6日時点·10月12日試験まで残り18週·6月第1週にI種105+論述25点を先に読み、II種100問70点と混同していた場合、6月第2週に本記事の比較表で確認してから演習計画を立て直す逆算が定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の受験要項です。

この記事の要点

本記事を読むと、たとえばI種とII種を同一試験と誤解していた場合に、形式·合格基準の比較表とexam-eligibility/concurrent-exam-rulesとの使い分けが分かり、100問70点のII種演習計画を正しく立て直せます。

1類似資格比較の全体像（II種100問70点を基準に）

II種ラインケアは100問·四択一·120分·70点以上·7領域です。I種·III種·衛生管理者は別コース·別試験·別合格基準です。要項が正本です。

| 基準 | II種ラインケア | 確認先 |
| --- | --- | --- |
| 問題数 | 100問 | 要項 |
| 時間 | 120分 | 要項 |
| 合格 | 70点以上 | pass-score |
| 領域 | 7領域 | 公式テキスト |

たとえば6月第1週に要項PDFを開き、II種章だけを読んで100問70点を確認してから演習を開始する流れが定番です。I種105+論述25点の基準と混同しないでください。

2I種·II種·III種の形式比較表（問題数·合格基準·論述）

メンタルヘルス·マネジメント検定はI種·II種·III種で形式が異なります。本記事の対象はII種ラインケアです。

| コース | 形式 | 合格基準 |
| --- | --- | --- |
| II種ラインケア | 100問·120分 | 70点以上 |
| I種 | 105点+論述25点 | 別基準 |
| III種 | 別形式 | 要項確認 |
| 併願 | 別申込 | concurrent-exam-rules |

  • 例えば6月第1週にI種要項を読み
  • 「II種も論述25点がある」と誤解した場合
  • 6月第2週に本記事の比較表で100問70点を確認し演習計画を立て直す流れが定番

3衛生管理者（30問180点）との違い表（別試験·別目的）

衛生管理者試験は30問·180点満点·別の国家資格試験です。II種100問70点とは出題範囲·合格基準·登録制度が異なります。

| 項目 | II種ラインケア | 衛生管理者 |
| --- | --- | --- |
| 問題数 | 100問 | 30問 |
| 満点 | 100点 | 180点 |
| 合格 | 70点以上 | 別基準 |
| 登録 | なし | 国家登録 |

たとえば6月第2週に「II種合格＝衛生管理者免許」と誤解している場合、6月第3週にregistration-after-pass記事と本記事の比較表で確認する流れが定番です。

4受験目的·併願の判断表（管理監督者向けII種優先）

管理監督者のラインケア実践が目的ならII種ラインケア100問70点が第一候補です。併願·同日受験不可はconcurrent-exam-rules記事で確認します。

| 目的 | 第一候補 | 併願 |
| --- | --- | --- |
| ラインケア | II種 | 別日 |
| 統括·論述 | I種 | 別要項 |
| 衛生管理 | 衛生管理者 | 別試験 |
| 併願 | 要項確認 | 別申込 |

  • 例えば7月15日II種申込開始なら
  • 7月第1週にconcurrent-exam-rules記事で同日同時刻不可を確認し
  • 100問70点の演習は並行開始する流れが定番

5exam-eligibility/concurrent-exam-rules/exemption-systemとの連携

類似資格比較に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| compare-similar-qualifications（本記事） | 形式比較·正本 |
| exam-eligibility | 受験資格詳細 |
| concurrent-exam-rules | 併願·同日不可 |
| exemption-system | 免除·要項確認 |

  • たとえば6月第1週に本記事で比較表
  • 6月第2週にexam-eligibilityで資格表
  • 7月第1週にconcurrent-exam-rulesで併願ルールを確認する流れが定番

III種の手続きを流用しないでください。

6よくある質問

II種と衛生管理者試験は同じですか？
別試験です。II種ラインケアは100問·70点以上·120分、衛生管理者は30問·180点満点の国家資格試験です。たとえば6月第2週に本記事の比較表を読み、100問70点のII種演習計画と混同していないか確認してください。100問120分·70点以上·7領域がII種の形式です。
I種とII種を同じ日に受けられますか？
同日同時刻にII種（100問·120分）とI種（105点＋論述25点）を併受験することはできません。例えば10月12日（日）のII種を受ける場合、同じ日·同時間帯のI種は選べないため、別試験日に分けて申し込んでください。詳細はconcurrent-exam-rules記事で確認します。105点＋論述25点はI種の基準であり、II種70点とは異なります。
compare-similar-qualificationsとexam-eligibilityはどう使い分けますか？
compare-similar-qualifications（本記事）はI種·III種·衛生管理者との形式·合格基準比較に特化、exam-eligibilityはII種ラインケアの受験資格詳細が正本です。たとえば6月第1週に本記事で比較表、6月第2週にexam-eligibilityで資格表を確認する順が定番です。70点の詳細はpass-scoreが正本です。
