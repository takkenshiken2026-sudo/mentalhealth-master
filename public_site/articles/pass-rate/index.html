メンタルヘルス・マネジメント検定II種の合格率と難易度の見方

メンタルヘルス・マネジメント検定II種（ラインケア）の合格率は、年度·受験者構成で変動するため、数字だけで難易度を判断しません。たとえば6月6日時点で要項を開き、100問·四択一·120分·70点以上·7領域の形式を確認し、演習100問中70問正解（70点）を自分の合格ラインとする逆算が定番です。本記事では合格率と難易度の見方を表にまとめ、統計の読み方はpass-rate-how-to-read·合格基準の詳細はpass-scoreと役割分担します。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の試験のご紹介です。

この記事の要点

本記事を読むと、たとえば公式サイトの合格率60％前後を見て「簡単」と判断すべきか、演習68問正解（68点）の自分に何週間の追加学習が必要かの基準が分かり、100問70点合格の現実的な難易度見積もりができます。

1合格率と難易度の見方の全体像

II種ラインケアの難易度は、合格率単体では判断しません。100問·70点·7領域の形式と、自分の演習得点をセットで見積もります。

| 軸 | 内容 |
| --- | --- |
| 形式 | 100問·四択一·120分 |
| 合格 | 70点（70問正解） |
| 範囲 | 7領域 |
| 統計 | 年度で変動·要項確認 |

たとえば6月6日時点で演習100問中68問正解（68点）なら合格ラインに届いていません。合格率60％前後でも自分の得点が基準です。I種105+論述25点の合格率と混同しないでください。

2要項で確認する合格基準70点

合格基準は受験要項·試験のご紹介が正本です。100点満点中70点以上＝70問以上の正解です。

| 項目 | 正本 |
| --- | --- |
| 問題数 | 100問 |
| 選択 | 四択一 |
| 時間 | 120分 |
| 合格 | 70点以上 |

  • 例えば申込前に要項PDFを開き
  • 「100問·120分·70点以上」を1行メモし
  • 演習の目標を70問正解に固定する流れが定番

衛生管理者試験30問180点の基準と混同しないでください。

3合格率だけで判断しない理由

合格率は受験者の構成·年度·試験回で変動します。数字が高くても自分の演習が70点未満なら準備不足です。

| 誤解 | 実際 |
| --- | --- |
| 合格率60％＝簡単 | 演習得点が基準 |
| 合格者多数＝余裕 | 7領域弱点は残る |
| 前年比↑＝楽 | 出題傾向は別 |
| 統計だけ見れば十分 | 自分の正答率必須 |

たとえば演習100問中75問正解（75点）でも、「相談対応」領域だけ55％なら本番で偶然の誤答が70点割れのリスクがあります。7領域すべて60％以上を目指してください。

4演習得点で測る難易度の目安表

自分の演習100問の正解数で難易度を測ります。70問正解（70点）を最低ラインとします。

| 演習得点 | 判断 |
| --- | --- |
| 75点以上 | 合格圏内·弱点1領域補強 |
| 70〜74点 | 合格圏内·全領域60％確認 |
| 65〜69点 | 不足·弱点に週5時間追加 |
| 64点以下 | 基礎復習·7領域再整理 |

  • 例えば8月第2週の演習100問中65問正解（65点）なら
  • 55％未満の領域1つを特定し
  • 9月第1週までに週5時間×4週で20問追加する計画が定番

5pass-rate-how-to-read/pass-scoreとの役割分担

合格率に関する記事は3本に役割分担しています。

| 記事 | 役割 |
| --- | --- |
| pass-rate（本記事） | 合格率·難易度の見方 |
| pass-rate-how-to-read | 数字·母数の読み方 |
| pass-score | 70点·70問正解の詳細 |

  • たとえば6月第1週に本記事で難易度の3軸を確認
  • 同日にpass-rate-how-to-readで公式統計の母数を読み
  • 演習目標はpass-scoreの70問正解ラインに合わせる流れが定番

初学者計画はexam-difficulty·study-plan-beginnerと併用してください。

6よくある質問

合格率はどこで確認しますか？
合格率·統計は試験のご紹介（公式）·受験要項が正本です。年度ごとに更新されるため、申込前に必ず最新ページを開いてください。たとえば6月第1週に公式サイトの統計をメモし、同週に演習100問中70問正解（70点）を自分の合格ラインとして記録する流れが定番です。数字の読み方·母数の確認はpass-rate-how-to-read記事を併用してください。
合格率60％なら簡単ですか？
いいえ。合格率は受験者構成で変動し、自分の演習得点が70点未満なら準備不足です。例えば演習100問中68問正解（68点）·「法令」領域50％なら、8月第1〜4週に週5時間追加で20問解き直し、9月第1週に70問正解を目指してください。100問·70点·7領域の形式は毎回同じです。
pass-rateとpass-rate-how-to-readはどう違いますか？
pass-rate（本記事）は合格率·難易度の総合的な見方、pass-rate-how-to-readは公式統計の数字·母数·年度比較の読み方に特化しています。たとえば6月第1週に本記事で演習70点ラインを確認、同日にpass-rate-how-to-readで「受験者数·合格者数」の表の読み方を学ぶ順が定番です。70点の詳細はpass-scoreが正本です。
