メンタルヘルス・マネジメント検定II種の傾聴・アクティブリスニング｜管理監督者の面談で使う考え方

メンタルヘルス・マネジメント検定II種（ラインケア）の傾聴·アクティブリスニングは、100問·7領域の領域⑤相談対応で管理監督者の面談·初回相談における傾聴·共感·非言語配慮が四択で問われる論点の正本です。相談·紹介5ステップ全体はconsultation-referral記事、4つのケア全体像はline-careと役割分担します。たとえば6月6日開始·10月12日試験まで残り18週·6月第2週演習10問·傾聴5問中3問正解（60％）なら、「即座に診断·助言」誤答を整理してから6月第3週7日後に解き直す逆算が定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の試験のご紹介です。

この記事の要点

本記事を読むと、たとえば演習10問·傾聴5問中3問正解の場合に、面談での傾聴手順·非言語配慮·診断·助言との線引きが分かり、consultation-referral/line-careとの使い分けも70点合格に向けて整理できます。

1傾聴·アクティブリスニングの全体像（領域⑤·100問·70点）

II種ラインケアの傾聴は相談者の話を聴き·理解を示す管理監督者の基本スキルです。即座の診断·助言·説教は誤答の典型です。100問·120分·70点以上·7領域が前提です。

| 要素 | 正解 | 誤答 |
| --- | --- | --- |
| 傾聴 | 話を聴く | 即座に診断 |
| 共感 | 気持ちに寄り添う | 否定·説教 |
| 非言語 | うなずき·視線 | スマホ操作 |
| 記録 | 要点のみ | 詳細な病歴 |

  • たとえば6月第2週演習10問·傾聴5問中3問正解（60％）なら
  • 6月第3週7日後に同5問を解き直し
  • 正答率70％以上を目指す流れが定番

I種105+論述25点の面談論点と混同しないでください。

2面談の傾聴手順表（初回相談·安全配慮）

初回面談では傾聴·安全配慮が最優先です。医学的診断·治療方針の決定は医師の領域であり管理監督者は行いません。

| 順序 | 行動 | 禁止 |
| --- | --- | --- |
| 1 | プライバシー確保 | 公開場所 |
| 2 | 傾聴·うなずき | 即座に助言 |
| 3 | 要約·確認 | 否定 |
| 4 | 支援継続の約束 | 放り出し |
| 5 | 必要時専門機関紹介 | 一人完結 |

  • 例えば6月第2週にconsultation-referral記事を読み
  • 演習10問·傾聴3問中2問正解（67％）なら
  • 6月第3週7日後に3問解き直す流れが定番

3アクティブリスニングの非言語·言語技法表

アクティブリスニングは非言語（うなずき·視線·姿勢）と言語（要約·オウム返し·開かれた質問）の組み合わせです。

| 技法 | 例 | 効果 |
| --- | --- | --- |
| うなずき | 相づち | 理解の示し |
| 要約 | 「〜とおっしゃった」 | 確認 |
| 沈黙 | 5秒待つ | 話を促す |
| 開かれた質問 | 「どう感じますか」 | 深掘り |

  • たとえば6月第3週演習20問·非言語3問中1問正解（33％）なら
  • 6月第4週に「スマホを見ながら傾聴」誤答2問を解き直し
  • 正答率70％以上を目指す流れが定番

4傾聴設問の頻出誤答表（診断·助言·放り出し）

傾聴·面談設問の頻出誤答は、管理監督者が診断する·即座に助言·解決策を押し付ける·相談後に放り出すが典型です。

| 誤答 | 正解 | 確認先 |
| --- | --- | --- |
| 上司が診断 | 傾聴·連携 | 本記事 |
| 即座に休職勧告 | 傾聴→専門機関 | consultation-referral |
| 紹介＝終了 | フォロー継続 | consultation-referral |
| 詳細な病歴記録 | 要点のみ | 公式テキスト第5章 |

  • 例えば7月第1週演習20問·傾聴8問中4問正解（50％）なら
  • 7月第2週に本記事の誤答表を暗記し
  • 同8問で正答率70％以上を目指す流れが定番

5consultation-referral/line-care/suicide-responseとの連携

傾聴·面談に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| active-listening（本記事） | 傾聴·面談·非言語 |
| consultation-referral | 5ステップ全体 |
| line-care | 4つのケア一覧 |
| suicide-response | 自殺念慮·安全配慮 |

  • たとえば6月第2週に本記事で傾聴手順表
  • 同日にconsultation-referralで5ステップ
  • 6月第3週にline-careで4ケア表を確認する流れが定番

III種の論点と取り違えないでください。

6よくある質問

面談で管理監督者は医学的診断を行いますか？
医学的診断·治療判断は医師の役割であり、管理監督者が代行する選択肢は誤答です。たとえば6月第2週演習10問·「上司がうつ病と診断」選択肢が出たら誤答です。6月第3週に本記事の傾聴手順表を読み直し、傾聴から専門機関紹介の10問を解き直してください。100問120分·70点以上·7領域がII種の形式です。
アクティブリスニングで沈黙は使いますか？
相談者が話す時間を確保するため短い沈黙は有効な技法です。例えば6月第3週演習20問·「沈黙は傾聴に不向き」2問が誤答なら、6月第4週に本記事の非言語技法表を確認し同分野10問を解き直す流れが定番です。105点＋論述25点はI種の基準であり、II種70点とは異なります。
active-listeningとconsultation-referralはどう使い分けますか？
active-listening（本記事）は傾聴·面談·非言語配慮に特化、consultation-referralは相談·紹介5ステップの全体フローが正本です。たとえば6月第2週に本記事で傾聴手順表、同日にconsultation-referralで5ステップ表を確認する順が定番です。70点の詳細はpass-scoreが正本です。
