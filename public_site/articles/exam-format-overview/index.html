メンタルヘルス・マネジメント検定II種の試験形式の概要｜100問120分70点7領域

メンタルヘルス・マネジメント検定II種（ラインケア）の試験形式の概要は、100問·四択一·120分·70点以上·7領域という本番形式を最初に押さえる数値·構造の正本です。管理監督者向けラインケアコースの合格基準·出題範囲·時間配分の全体像を本記事で表に整理し、CBT·マークシート対策はcbt-computer-exam·試験概要·入口はoverviewと役割分担します。たとえば6月6日時点·10月12日試験まで残り18週·6月第1週要項で100問120分70点確認·6月第2週演習50問·35問正解（70％）なら、8月第1週100問模試70点を逆算する流れが定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の受験要項です。

この記事の要点

本記事を読むと、たとえば受験初年度で形式が分からない場合に、100問120分70点7領域の形式表とcbt-computer-exam/overviewとの使い分けが分かり、学習計画の土台が整理できます。

1試験形式の数値一覧（100問·120分·70点·7領域）

II種ラインケアの試験形式は受験要項が正本です。おおむね次の数値で固定されています。

| 項目 | 内容 | 確認先 |
| --- | --- | --- |
| 問題数 | 100問 | 要項 |
| 形式 | 四択一 | 要項 |
| 時間 | 120分 | 要項 |
| 合格 | 70点以上 | pass-score |
| 範囲 | 7領域 | subjects |

たとえば6月第1週要項PDF·100問120分70点の記載を1枚の形式表にまとめ、6月第2週演習50問·35問正解（70％）で実力確認する流れが定番です。I種105+論述25点の形式と混同しないでください。

27領域出題範囲と公式テキスト章立て対応表

7領域は公式テキストの章立てとおおむね1対1で対応します。演習の7領域タグと章を対応づけて学習します。

| 領域 | テキスト章 | 演習目安 |
| --- | --- | --- |
| ①意義·役割 | 第1章 | 10問 |
| ②基礎知識 | 第2章 | 10問 |
| ③環境評価 | 第3章 | 10問 |
| ④個別配慮 | 第4章 | 10問 |
| ⑤相談対応 | 第5章 | 15問 |
| ⑥社内推進 | 第6章 | 10問 |
| ⑦法令 | 第7章 | 15問 |

例えば6月第3週·第1〜2章読了·演習20問·14問正解（70％）なら、6月第4週第3章着手と同20問7日後解き直しが定番です。

3120分·100問の時間配分と合格ライン表

100問120分は平均1問72秒です。70点（70問正解）が合格ラインです。cbt-computer-exam記事で詳細配分を確認します。

| 区間 | 問題 | 時間 | 目安 |
| --- | --- | --- | --- |
| 前半 | 1〜50問 | 60分 | 1問72秒 |
| 中盤 | 51〜80問 | 36分 | 1問72秒 |
| 後半 | 81〜100問 | 24分 | 迷い短縮 |
| 合格 | 70問正解 | — | 70点 |

たとえば8月第1週100問模試110分·68問正解（68点）なら、8月第2週cbt-computer-exam記事の時間配分表で60分50問練習3回が定番です。

4演習得点と本番形式の対応表（70点判定）

演習100問中70問正解（70点）を本番合格の最低ラインとします。模試は120分制限で実施します。

| 演習得点 | 判断 | 次の一手 |
| --- | --- | --- |
| 75点以上 | 合格圏内 | 弱点1領域 |
| 70〜74点 | 合格圏内 | 全領域60％確認 |
| 65〜69点 | 不足 | 弱点20問追加 |
| 64点以下 | 基礎不足 | 7領域再整理 |

例えば9月第2週100問模試72問正解（72点）·「法令」領域50％なら、9月第3週法令20問追加で70点維持を目指す流れが定番です。

5cbt-computer-exam/overview/pass-scoreとの連携

試験形式に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| exam-format-overview（本記事） | 形式·数値正本 |
| cbt-computer-exam | マーク·時間配分 |
| overview | 試験概要·入口 |
| pass-score | 70点·合格基準 |

  • たとえば6月第1週に本記事で100問120分70点表
  • 6月第2週にoverviewで試験概要
  • 8月第1週にcbt-computer-examで120分模試対策を確認する流れが定番

III種の論点と取り違えないでください。

6よくある質問

試験形式の基本数値を教えてください
100問·四択一·120分·70点以上·7領域がII種ラインケアの基本形式です。たとえば6月第1週要項PDF·100問120分70点の記載を確認し、6月第2週1枚の形式表にまとめてカレンダーに貼る流れが定番です。数値·日程は要項が正本です。
7領域はどこで確認できますか？
公式テキスト目次·subjects記事·試験のご紹介（公式）の出題範囲が正本です。例えば6月第2週公式テキスト目次と7領域表を対応づけ、6月第3週演習20問·7領域各2〜3問で正答率70％以上を目指してください。105点＋論述25点はI種の基準であり、II種70点とは異なります。
exam-format-overviewとcbt-computer-examはどう使い分けますか？
exam-format-overview（本記事）は100問120分70点7領域の形式·数値が正本、cbt-computer-examはマーク塗り·塗り直し·120分時間配分に特化しています。たとえば6月第1週に本記事で形式表、8月第1週にcbt-computer-examで模試対策を確認する順が定番です。70点の詳細はpass-scoreが正本です。
