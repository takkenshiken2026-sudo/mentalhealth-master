メンタルヘルス・マネジメント検定II種の出題範囲の概要｜7領域一覧と学習の全体像

メンタルヘルス・マネジメント検定II種（ラインケア）の出題範囲の概要は、100問·120分·70点以上·7領域という試験形式に対応する学習範囲の全体像を一覧表で押さえる正本です。要項·シラバスの読み方はsyllabus-how-to-read記事、7領域の詳細配分はsubjectsと役割分担します。たとえば6月6日時点·10月12日試験まで残り18週·6月第2週公式テキスト目次未確認·演習10問·領域タグ不明なら、本記事の7領域表→6月第3週第1〜2章読了·演習20問という逆算が定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の試験のご紹介です。

この記事の要点

本記事を読むと、たとえば独学開始時に7領域の全体像が分からない場合、出題範囲一覧表とsyllabus-how-to-read/subjectsとの使い分けが分かり、100問70点の学習計画の土台が整理できます。

17領域出題範囲の全体像（100問·公式テキスト·70点）

II種ラインケアの出題範囲は7領域に分類されます。公式テキストの章立てとおおむね1対1で対応します。100問·120分·70点以上が前提です。

| 領域 | テキスト章 | 演習目安 |
| --- | --- | --- |
| ①意義·役割 | 第1章 | 10問 |
| ②基礎知識 | 第2章 | 10問 |
| ③環境評価 | 第3章 | 10問 |
| ④個別配慮 | 第4章 | 10問 |
| ⑤相談対応 | 第5章 | 15問 |
| ⑥社内推進 | 第6章 | 10問 |
| ⑦法令 | 第7章 | 15問 |

  • たとえば6月第2週に公式テキスト目次と7領域表を対応づけ
  • 6月第3週演習20問·14問正解（70％）なら
  • 6月第4週7日後に同20問を解き直す流れが定番

I種105+論述25点の範囲と混同しないでください。

2領域別の出題比重·学習優先度表

100問は7領域に分散出題されます。⑤相談対応·⑦法令は演習量を多めに設定するのが定番です。subjects記事で配分詳細を確認します。

| 領域 | 比重目安 | 優先度 |
| --- | --- | --- |
| ①意義·役割 | 中 | 基礎 |
| ②基礎知識 | 中 | 基礎 |
| ③環境評価 | 中 | 中 |
| ④個別配慮 | 中 | 高 |
| ⑤相談対応 | やや高 | 最優先 |
| ⑥社内推進 | 中 | 中 |

例えば6月第3週演習20問·領域⑤50％·領域⑦40％なら、6月第4週に⑤⑦各10問追加で正答率70％以上を目指す流れが定番です。

たとえば6月第3週·第1〜2章読了·演習20問·14問正解（70％）なら、6月第4週第3章着手と同20問7日後解き直しが定番です。III種の論点と取り違えないでください。

47領域横断の出題パターン表（主体·手順·数値）

100問は領域横断で主体·手順·数値が入れ替わって出題されます。7領域すべて60％以上が安全ラインです。

| パターン | 典型 | 領域 |
| --- | --- | --- |
| 主体混同 | 上司が診断 | ①⑤ |
| 手順逆転 | 紹介前に診断 | ⑤ |
| 数値境界 | 49/50人 | ①⑦ |
| 制度混同 | EAP=産業医 | ⑤ |
| 個票開示 | 結果全部見る | ③⑥ |

例えば7月第1週演習30問·主体混同5問すべて誤答なら、7月第2週にconfusing-terms記事で混同語表10組を確認する流れが定番です。

5syllabus-how-to-read/subjects/exam-format-overviewとの連携

出題範囲に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| exam-scope-overview（本記事） | 7領域一覧·正本 |
| syllabus-how-to-read | 要項·シラバス読み方 |
| subjects | 7領域配分·詳細 |
| exam-format-overview | 100問120分70点 |

たとえば6月第2週に本記事で7領域表、6月第3週にsyllabus-how-to-readで要項確認·6月第4週にsubjectsで配分表を確認する流れが定番です。衛生管理者30問180点の範囲を流用しないでください。

6よくある質問

7領域の出題範囲はどこで確認できますか？
試験のご紹介（公式）·公式テキスト目次·本記事の7領域表が正本です。たとえば6月第2週に公式テキスト目次と7領域表を対応づけ、6月第3週演習20問·7領域各2〜3問で正答率70％以上を目指してください。100問120分·70点以上·7領域がII種の形式です。配分詳細はsubjectsが正本です。
exam-scope-overviewとsubjectsはどう使い分けますか？
exam-scope-overview（本記事）は7領域一覧·テキスト章立て対応·学習全体像が正本、subjectsは7領域別配分·出題傾向·演習目安に特化しています。例えば6月第2週に本記事で7領域表、6月第4週にsubjectsで配分表を確認する順が定番です。105点＋論述25点はI種の基準であり、II種70点とは異なります。
syllabus-how-to-readは出題範囲確認にどう使いますか？
syllabus-how-to-readは受験要項·シラバスの読み方·版改定確認手順が正本です。たとえば6月第2週に本記事で7領域表、6月第3週にsyllabus-how-to-readで要項PDF·100問70点の記載を確認する順が定番です。70点の詳細はpass-scoreが正本です。
