試験当日の流れと注意点｜メンタルヘルス二種マスター受験ガイド

メンタルヘルス・マネジメント検定II種（ラインケア）の試験当日は、流れを知っているだけでは足りず、持ち物·時間配分·70点戦略の3点を前日までに確認する必要があります。たとえば10月12日（日）10:00開始·100問120分なら、前日21:00までに持ち物チェック·1問72秒の時間配分·70点（100問中70問正解）の得点ラインを逆算するのが定番です。本記事では当日の注意点を表にまとめ、会場到着から退場までの流れはexam-day-flowと役割分担します。

1持ち物チェック（前日まで）

試験当日の持ち物は、受験票·要項が正本です。前日21:00までに次の5点を確認してください。

| # | 持ち物 | 確認 |
| --- | --- | --- |
| 1 | 受験票 | 氏名·会場·時刻 |
| 2 | 身分証 | 申込時と一致 |
| 3 | 筆記用具 | 黒または青 |
| 4 | 時計 | 非電子式推奨 |
| 5 | 水分 | 要項·会場指示 |

たとえば10月11日（土）21:00に持ち物をカバンに入れ、10月12日（日）7:00に最終確認するリマインダーを設定します。スマートフォンは要項どおり電源OFF·保管が原則です。当日の流れはexam-day-flowのタイムライン節で確認してください。

2時間配分の基本（100問÷120分）

100問·120分の試験では、1問あたり約72秒が目安です。長文事例（相談対応等）は90〜120秒かかることもあります。

| 到達問数 | 目安時刻（10:00開始） |
| --- | --- |
| 25問 | 10:30 |
| 50問 | 11:00 |
| 75問 | 11:30 |
| 100問 | 12:00 |

  • 例えば10:00開演·11:00時点で40問しか解けていない場合
  • 短い問題を優先し
  • 迷う問題はマークして後回しにし

I種105+論述25点の時間感覚では測らないでください。衛生管理者30問180点も別試験です。

370点合格の得点戦略

II種ラインケアの合格基準は100点満点中70点以上（70問正解）です。全問完答より、70問を確実に取る戦略が定番です。

| 戦略 | 内容 |
| --- | --- |
| 確実に取る | 得意7領域から |
| 捨て問 | 3分超で迷う問題 |
| 見直し | 最後15分 |
| マーク | 迷い問題を先送り |

たとえば演習100問中75問正解（75点）の状態なら合格圏内ですが、「相談対応」領域だけ55％なら本番で偶然の誤答が致命傷になります。7領域すべて60％以上を目指し、pass-score記事で合格基準の詳細を確認してください。

4exam-day-flowとの役割分担

本記事は「持ち物·時間配分·70点戦略」、exam-day-flowは「会場到着から退場までの時系列」に特化しています。

| 記事 | 役割 |
| --- | --- |
| exam-day-guide（本記事） | 持ち物·配分·70点 |
| exam-day-flow | 到着〜退場の流れ |
| exam-last-minute | 直前1週間チェック |

  • 例えば試験1週前にexam-last-minuteで弱点確認
  • 前日に本記事で持ち物·時間配分を確認
  • 当日朝にexam-day-flowのタイムライン（9:00到着等）を見直す流れが定番

5体調管理と当日の心構え

試験当日は120分の集中力が求められます。前日の睡眠·当日の食事·体調不良時の判断を前もって決めておきます。

| 項目 | 目安 |
| --- | --- |
| 睡眠 | 前日7時間以上 |
| 食事 | 試験2時間前 |
| 体調不良 | 要項·会場連絡先 |
| 当日朝 | 持ち物最終確認 |

たとえば10月11日22:00就寝·10月12日7:00起床·8:00朝食·8:30出発（10:00開始·通勤30分）のスケジュールが定番です。38℃以上の発熱がある場合は、要項の欠席·再受験規定を確認してください。

6よくある質問

試験前日に何を確認すべきですか？
前日21:00までに持ち物5点（受験票·身分証·筆記用具·時計·水分）をそろえ、100問120分の時間配分表（1問72秒）を1枚にまとめます。たとえば10月11日21:00にカバン準備·22:00就寝·10月12日7:00最終確認のリマインダーを設定してください。exam-day-flowのタイムライン（9:00到着等）も前日に読んでおきます。
70点を確保するには何問正解すればよいですか？
100問中70問以上の正解（70点以上）が合格基準です。全問完答より、70問を確実に取る戦略が定番で、3分超で迷う問題はマークして後回しにします。例えば演習100問中72問正解（72点）なら合格圏内ですが、7領域のうち1領域だけ55％なら本番リスクが残ります。pass-score記事で合格基準の詳細を確認してください。
当日の流れと注意点はどこで確認しますか？
当日の時系列（到着〜退場）はexam-day-flow、持ち物·時間配分·70点戦略は本記事がそれぞれの正本です。たとえば試験1週前にexam-last-minute·前日に本記事·当日朝にexam-day-flowの順で読むと漏れが減ります。105点＋論述25点はI種の基準であり、II種とは異なります。
