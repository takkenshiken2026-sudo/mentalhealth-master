メンタルヘルス・マネジメント検定II種の模試日程と学習計画

メンタルヘルス・マネジメント検定II種（ラインケア）の模試は、100問·四択一·120分·70点以上の本番形式で試験8週前·4週前·2週前に計画的に入れるのが定番です。たとえば10月12日（日）10:00開始まで残り18週なら、8月第2週に100問模試1回目·9月第2週に2回目·10月第1週に直前模試という逆算が定番です。本記事では模試日程逆算表をまとめ、週間·月間全体はself-study-schedule·直前模試手順はfinal-mock-last-runと役割分担します。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の試験のご紹介です。

この記事の要点

本記事を読むと、たとえば10月12日試験まで残り18週の場合に、100問120分の模試をいつ·何回入れるか、模試後の弱点20問追加のタイミングが分かり、70点（70問正解）合格の演習計画が立てられます。

  • 100問120分
  • 模試3回
  • 8週前逆算
  • 70問正解
  • mock連携

1模試日程逆算の全体像（100問120分）

II種ラインケアの模試は、100問·120分·70点以上の本番形式で実施します。試験日から逆算して3回入れるのが定番です。

| 回 | タイミング | 目的 |
| --- | --- | --- |
| 1回目 | 8週前 | 全体把握·70点確認 |
| 2回目 | 4週前 | 弱点補強後の確認 |
| 3回目 | 2週前 | 直前模試·70問確保 |

たとえば10月12日試験なら、8月第2週·9月第2週·10月第1週に100問120分模試を入れる流れが定番です。I種105+論述25点の模試形式と混同しないでください。

218週モデルの模試日程表

残り18週から試験日までの模試·学習逆算例です。

| 残り週 | タスク |
| --- | --- |
| 18〜12週 | 基礎·7領域テキスト |
| 10週 | 演習50問·領域別 |
| 8週 | 100問模試1回目 |
| 6週 | 弱点20問追加 |
| 4週 | 100問模試2回目 |
| 2週 | 100問模試3回目（直前） |

  • 例えば6月6日開始·10月12日試験なら
  • 8月第2週に模試1回目·72問正解（72点）を記録し
  • 55％未満1領域に20問追加する流れが定番

3模試当日の100問120分ペース表

模試も本番と同じ100問120分·10:00開始想定で50問到達時刻·見直し15分を記録します。

| 時刻 | 目安 | 記録 |
| --- | --- | --- |
| 10:00 | 開始 | — |
| 11:00 | 50問到達 | ペース確認 |
| 11:30 | 75問到達 | 迷い切り上げ |
| 11:45 | 見直し開始 | 15分確保 |
| 12:00 | 提出 | 70問以上確認 |

たとえば8月第2週の模試で11:00に48問なら5分遅れですが、長文3問を後回しにすれば11:30までに75問到達は可能です。時間配分はexam-day-guideが正本です。

4模試後の弱点分析と20問追加

模試後は7領域の正答率を記録し、55％未満の領域1つに20問追加で解き直します。

| 模試得点 | 判断 | 追加 |
| --- | --- | --- |
| 75点以上 | 合格圏内 | 弱点1領域20問 |
| 70〜74点 | 最低ライン | 全領域60％確認 |
| 65〜69点 | 不足 | 弱点3領域·60問 |
| 64点以下 | 基礎復習 | 7領域再整理 |

  • 例えば8月第2週の模試68問正解（68点）·「法令」領域50％なら
  • 8月第3〜4週に同分野20問を週2回解き直し
  • 9月第2週の模試2回目で70問正解を目指す流れが定番

5self-study-schedule/final-mock-last-runとの連携

模試計画に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| simulation-exam-schedule（本記事） | 模試日程逆算 |
| self-study-schedule | 週間·月間全体 |
| final-mock-last-run | 直前模試手順 |

  • たとえば6月第2週にself-study-scheduleで18週表を作成
  • 8月第1週に本記事で模試3回の日程を確定
  • 10月第1週にfinal-mock-last-runで直前模試の手順·70問確保を確認する流れが定番

6よくある質問

模試は何回·いつ実施すればよいですか？
100問120分の本番形式模試は、試験8週前·4週前·2週前の3回が定番です。たとえば10月12日試験なら、8月第2週·9月第2週·10月第1週に100問模試·70問正解以上を目指してください。模試後は7領域の正答率を記録し、55％未満1領域に20問追加で解き直します。
模試68点なら合格できますか？
68点は合格ライン（70点）に届いていません。55％未満の領域1つを特定し、週5時間×2週で演習20問＋用語10語を追加するのが定番です。例えば8月第2週の模試68問正解（68点）·「相談対応」領域55％なら、8月第3〜4週に同分野20問を解き直し、9月第2週の模試2回目で70問正解を目指してください。
simulation-exam-scheduleとfinal-mock-last-runはどう使い分けますか？
simulation-exam-schedule（本記事）は模試3回の日程逆算·弱点分析、final-mock-last-runは試験5日前の直前模試手順·70点確保に特化しています。たとえば8月第1週に本記事で模試日程を確定、10月第1週にfinal-mock-last-runで直前模試·見直し15分の手順を確認する順が定番です。100問120分·70点以上がII種ラインケアの形式です。
