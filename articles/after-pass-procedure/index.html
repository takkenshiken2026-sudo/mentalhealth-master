メンタルヘルス・マネジメント検定II種の合格後の手続き

メンタルヘルス・マネジメント検定II種（ラインケア）の合格後の手続きは、合格発表→合格証交付→社内報告→現場活用の順序で進める手続きの正本です。合格証の記載確認はpass-announcement-guide記事、登録·免許の違いはregistration-after-passと役割分担します。たとえば6月6日時点·10月12日試験まで残り18週·6月15日合格発表·7月上旬合格証交付の年度なら、6月第3週に発表確認·7月第1週に社内報告という逆算が定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の受験要項です。

この記事の要点

本記事を読むと、たとえば6月15日合格発表·7月上旬合格証交付の場合に、合格後手続きの順序表とregistration-after-pass/pass-announcement-guideとの使い分けが分かり、社内報告まで漏れなく進められます。

1合格後手続きの全体像（発表→交付→報告→活用）

II種ラインケア合格後の手続きは日産協の公開試験案内·受験要項が正本です。100問·120分·70点以上合格の記録を順序どおり確認します。

| 段階 | 時期 | 確認内容 |
| --- | --- | --- |
| 合格発表 | 試験後2〜3週 | Web等の案内 |
| 合格証交付 | 発表後1〜2週 | 郵送·Web |
| 社内報告 | 交付後1週 | 人事·安全衛生 |
| 現場活用 | 継続 | 管理監督者実践 |

たとえば6月15日合格発表·7月上旬交付の年度なら、6月第3週にpass-announcement-guide記事で発表確認·7月第1週社内報告を逆算する流れが定番です。衛生管理者の登録免許手続きと混同しないでください。

2合格証の確認項目表（II種ラインケア·氏名一致）

合格証には氏名·試験名·コース名·合格年月日が記載されます。II種ラインケアであることを申込情報と照合してください。

| 項目 | チェック | 不一致時 |
| --- | --- | --- |
| 試験名 | II種·ラインケア | 要項問合せ |
| 氏名 | 身分証一致 | 再発行 |
| 合格日 | 発表と一致 | 要項確認 |
| 再発行 | 要項手続 | 日産協 |

例えば7月5日交付の合格証に「II種ラインケア」と記載がある場合、7月第1週に申込時の氏名表記と並べて照合する流れが定番です。

3登録·免許の違い表（II種は国家資格登録なし）

メンタルヘルス·マネジメント検定II種は衛生管理者のような国家資格登録制度とは異なります。registration-after-pass記事で詳細を確認します。

| 試験 | 登録·免許 | 合格証の用途 |
| --- | --- | --- |
| II種ラインケア | なし | 研修修了証明 |
| I種 | 論述あり | 別基準105+25点 |
| 衛生管理者 | 国家登録 | 別試験30問180点 |
| III種 | 要項確認 | 別コース |

たとえば7月第1週にregistration-after-pass記事を読み、「II種合格＝衛生管理者免許」と誤解していないか確認する流れが定番です。

4社内報告·研修記録への反映手順表

多くの事業場では合格後に人事·安全衛生担当へ報告し、研修履歴·管理監督者能力開発記録に反映します。社内規程を先に確認します。

| 報告先 | 提出物 | 期限例 |
| --- | --- | --- |
| 人事 | 合格証写し | 7月1日 |
| 安全衛生 | 体制図更新 | 7月第2週 |
| 直属上司 | 報告メモ | 交付後3日 |

  • 例えば7月1日までに合格証写し提出の社内ルールがある場合
  • 6月第4週にPDF保存·印刷を済ませ
  • 6月第4週金曜に再確認する流れが定番

5registration-after-pass/pass-announcement-guide/after-passとの連携

合格後に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| after-pass-procedure（本記事） | 手続き順序·正本 |
| pass-announcement-guide | 合格発表の確認 |
| registration-after-pass | 登録·免許の違い |
| after-pass | 合格証·社内報告概要 |

  • たとえば6月第3週にpass-announcement-guideで発表確認
  • 7月第1週に本記事で手続き表
  • 同日にregistration-after-passで登録不要を確認する流れが定番

III種の手続きを流用しないでください。

6よくある質問

合格証はいつ·どの方法で受け取れますか？
交付時期·方法（郵送·Web表示等）は受験した公開試験回の要項·合格発表案内が正本です。たとえば6月試験合格で7月上旬交付の年度では、6月第4週に日産協サイトで交付ステータスを確認する習慣が有効です。氏名の旧字体不一致があると再手続が必要になるため、申込時の表記と合格証を並べて照合してください。
II種合格後に登録や免許の申請は必要ですか？
II種は衛生管理者のような国家資格登録制度とは異なります。例えば合格証を社内研修の修了証明として使う場合と、別途会社が求める管理監督者研修を受ける場合は別手続です。7月第1週にregistration-after-pass記事で登録·免許の要否を確認してください。I種·III種の手続きを流用しないでください。
after-pass-procedureとafter-passはどう使い分けますか？
after-pass-procedure（本記事）は合格後手続きの順序·合格証·登録違いの正本、after-passは合格証·社内報告·現場活用の概要に特化しています。たとえば6月第3週にpass-announcement-guideで発表確認、7月第1週に本記事で手続き表、同日にafter-passで社内報告を確認する順が定番です。70点の詳細はpass-scoreが正本です。
