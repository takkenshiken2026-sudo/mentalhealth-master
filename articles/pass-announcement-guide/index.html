メンタルヘルス・マネジメント検定II種の合格発表の確認方法｜合否·合格証の正本

メンタルヘルス・マネジメント検定II種（ラインケア）の合格発表の確認方法は、合否結果の確認手順·合格証交付の時期·II種ラインケア表記·氏名照合を1枚のチェック表にまとめる正本です。合格後手続きの順序はafter-pass-procedure記事、登録·免許の違いはregistration-after-passと役割分担します。たとえば10月12日試験·10月25日合格発表·11月上旬合格証交付の年度なら、10月第4週に本記事で合否確認·11月第1週after-pass-procedureで社内報告手順という逆算が定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の受験要項です。

この記事の要点

本記事を読むと、たとえば10月25日合格発表·11月上旬交付の場合に、合否確認·合格証チェック表とafter-pass-procedure/registration-after-passとの使い分けが分かり、合格後の最初の一歩が漏れなく進められます。

1合格発表確認の全体像（合否→交付→照合）

II種ラインケアの合格発表は受験した公開試験回の要項·合格発表案内が正本です。100問·120分·70点以上合格の記録を順序どおり確認します。

| 段階 | 時期目安 | 確認内容 |
| --- | --- | --- |
| 合否確認 | 試験後2〜3週 | Web等 |
| 合格証交付 | 発表後1〜2週 | 郵送·Web |
| 表記照合 | 交付後3日 | II種ラインケア |
| 社内報告 | 交付後1週 | 人事等 |

たとえば10月12日試験·10月25日合格発表·11月上旬交付なら、10月第4週に本記事で合否確認·11月第1週合格証照合が定番です。衛生管理者免許の交付手続きと混同しないでください。

2合否確認手順表（Web·受験番号·確認期限）

合否確認は要項記載のWebサイト·受験番号·確認期限に従います。不合格時は次回申込期間を同日にカレンダー登録します。

| 手順 | 内容 | 記録 |
| --- | --- | --- |
| 1 | 要項で確認方法 | URL |
| 2 | 受験番号準備 | メモ |
| 3 | 発表日に合否確認 | 日付 |
| 4 | 不合格時次回申込 | カレンダー |

例えば10月25日9時発表·10月第4週金曜合否確認·合格なら11月第1週交付待ち·不合格なら12月再受験申込期間確認が定番です。

3合格証の確認項目表（II種ラインケア·氏名·合格日）

合格証には氏名·試験名·コース名·合格年月日が記載されます。II種ラインケアであることを申込時の表記と照合してください。

| 項目 | チェック | 不一致時 |
| --- | --- | --- |
| 試験名 | II種·ラインケア | 要項問合せ |
| 氏名 | 身分証·申込一致 | 再発行 |
| 合格日 | 発表と一致 | 要項確認 |
| 再発行 | 要項手続 | 日産協 |

たとえば11月5日交付·「II種ラインケア」表記確認·11月第1週申込氏名と並べ照合·11月第2週社内報告準備が定番です。

4合格発表後の頻出誤解表（登録·免許·I種混同）

合格発表直後に登録·免許申請が必要と誤解しやすい点を整理します。registration-after-pass記事で詳細を確認します。

| 誤解 | 正解 | 確認先 |
| --- | --- | --- |
| 国家登録必要 | II種は不要 | registration-after-pass |
| I種と同手続 | 別基準 | 要項 |
| 衛生管理者免許 | 別試験 | 混同禁止 |
| III種手続流用 | 不可 | 要項 |

例えば11月第1週·「II種合格＝衛生管理者免許申請」と誤解していた場合、11月第1週registration-after-pass記事で登録不要を確認する流れが定番です。

5after-pass-procedure/registration-after-pass/after-passとの連携

合格発表·合格後に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| pass-announcement-guide（本記事） | 合否·合格証確認 |
| after-pass-procedure | 手続き順序·正本 |
| registration-after-pass | 登録·免許の違い |
| after-pass | 社内報告·活用概要 |

  • たとえば10月第4週に本記事で合否確認
  • 11月第1週にafter-pass-procedureで手続き表
  • 同日にregistration-after-passで登録不要を確認する流れが定番

III種の手続きを流用しないでください。

6よくある質問

合格発表はいつ·どこで確認しますか？
合否確認方法·時期は受験した公開試験回の要項·合格発表案内が正本です。たとえば10月12日試験·10月25日合格発表なら、10月第4週金曜に日産協サイトで合否を確認し、合格証交付時期をメモしてください。100問120分·70点以上·7領域がII種の形式です。
合格証の表記で確認すべき点は？
II種ラインケア·氏名·合格日の3点を申込情報と照合するのが定番です。例えば11月5日交付·氏名旧字体不一致なら再発行手続が必要です。11月第1週after-pass-procedure記事で社内報告手順を確認してください。105点＋論述25点はI種の基準であり、II種70点とは異なります。
pass-announcement-guideとafter-pass-procedureはどう使い分けますか？
pass-announcement-guide（本記事）は合格発表·合否·合格証確認が正本、after-pass-procedureは合格後手続きの順序·社内報告に特化しています。たとえば10月第4週に本記事で合否確認、11月第1週にafter-pass-procedureで手続き表を確認する順が定番です。70点の詳細はpass-scoreが正本です。
