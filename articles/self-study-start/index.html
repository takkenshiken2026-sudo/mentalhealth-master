メンタルヘルス・マネジメント検定II種の独学の始め方

メンタルヘルス・マネジメント検定II種（ラインケア）の独学の始め方は、試験のご紹介（公式）で受験資格·100問·120分·70点以上·7領域を確認したうえで、第1週に公式テキスト目次と7領域対応表を1枚にまとめる学習です。最初30日の詳細計画はfirst-30-days-plan記事、独学全体像はself-study-guideと役割分担します。たとえば6月6日開始·10月12日試験まで残り18週·6月第1週に公式要項確認·公式テキスト第1章30分/日·6月第2週末q/演習5問導入という逆算が定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の試験のご紹介です。

この記事の要点

本記事を読むと、たとえば6月6日開始·公式テキスト未購入の場合に、第1週の確認項目表とfirst-30-days-planへの接続点が分かり、独学の最初の一歩が具体化します。

1独学開始前の公式確認チェック表

独学を始める前に試験のご紹介（公式）で5項目をメモします。年度で変わるため毎年確認です。

| 項目 | 確認内容 | 記録 |
| --- | --- | --- |
| 受験資格 | 管理監督者等 | メモ |
| 試験形式 | 100問·四択一 | 120分 |
| 合格基準 | 70点以上 | 70問正解 |
| 出題範囲 | 7領域 | 目次対応 |
| 申込期限 | 年度ごと | カレンダー |

たとえば6月第1週に5項目を確認し、6月第2週に公式テキスト第1章を読み始める流れが定番です。I種105+論述25点の要項と混同しないでください。

2第1週の学習スケジュール表（30分/日·演習5問）

第1週は公式テキスト第1章の読み込みと7領域の位置づけ把握が中心です。週末に演習5問を試します。

| 曜日 | 時間 | 内容 |
| --- | --- | --- |
| 月〜金 | 30分/日 | 第1章読み |
| 土 | 30分 | 用語10語確認 |
| 日 | 60分 | q/演習5問 |
| 記録 | — | 7領域タグ |

例えば6月第1週·第1章読了·日曜q/演習5問·3問正解（60％）なら、6月第2週に第2章着手と同5問7日後解き直しが定番です。

3公式テキスト目次と7領域の対応づけ表

第1週に公式テキスト目次と7領域を1対1で対応づける表を作成します。subjects記事の7領域一覧と照合します。

| 領域 | テキスト章 | 第1週 |
| --- | --- | --- |
| ①意義·役割 | 第1章 | 読了 |
| ②ストレス基礎 | 第2章 | 着手 |
| ③④環境·配慮 | 第3〜4章 | 以降 |
| ⑤⑥⑦後半 | 第5〜7章 | 以降 |

たとえば6月第1週に第1章完了·演習5問·領域①3問中2問正解（67％）なら、6月第2週に第2章30分/日で進む流れが定番です。

4第1週末の演習5問導入と正答率記録

第1週末にq/演習5問を解き、7領域タグ別の正答率を記録します。解説を読む前に自分の答案をメモします。

| 手順 | 内容 | 時間 |
| --- | --- | --- |
| 1 | 5問通し | 30分 |
| 2 | 7領域タグ確認 | 10分 |
| 3 | 誤答理由メモ | 10分 |
| 4 | 7日後解き直し予定 | 5分 |

例えば6月第1週末·演習5問·2問誤答なら、6月第2週に誤答2問の用語をterms/で確認·6月第2週末7日後に同5問解き直しで正答率70％以上を目指す流れが定番です。

5first-30-days-plan/self-study-guideとの連携

独学開始に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| self-study-start（本記事） | 第1週·公式確認 |
| first-30-days-plan | 最初30日·章立て |
| self-study-guide | 独学全体像 |
| textbook-selection | テキスト版確認 |

  • 6月第2週にfirst-30-days-planで30日表
  • 6月第3週にself-study-guideで週次サイクルを確認する流れが定番

6よくある質問

独学は何から始めればよいですか？
試験のご紹介（公式）で100問·70点·7領域を確認し、第1週に公式テキスト第1章を30分/日で読むのが定番です。たとえば6月6日開始·10月12日試験（残り18週）なら、6月第1週に公式5項目確認·6月第2週末q/演習5問導入を目指してください。100問120分·70点以上·7領域がII種の形式です。
第1週で演習は何問解けばよいですか？
第1週末にq/演習5問·7領域タグ付きが定番です。例えば6月第1週末·5問·3問正解（60％）なら、6月第2週に誤答2問の用語をterms/で確認し、6月第2週末7日後に同5問で4問正解（80％）を目指してください。105点＋論述25点はI種の基準であり、II種70点とは異なります。
self-study-startとfirst-30-days-planはどう使い分けますか？
self-study-start（本記事）は第1週·公式確認·演習5問導入、first-30-days-planは最初30日の章立て·演習10問導入に特化しています。たとえば6月第1週に本記事で第1週計画、6月第2週にfirst-30-days-planで30日表を確認する順が定番です。70点の詳細はpass-scoreが正本です。
