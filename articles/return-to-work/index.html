職場復帰支援の5ステップ｜二種で覚える流れ

職場復帰支援は、休業開始から復帰後のフォローアップまでを段階的に進めます。流れを順番で覚えると選択肢を判断しやすくなります。

5ステップの流れ

  1. 休業開始および休業中のケア
  2. 主治医による職場復帰可能の判断
  3. 職場復帰の可否判断と職場復帰支援プランの作成
  4. 最終的な職場復帰の決定
  5. 職場復帰後のフォローアップ

管理監督者の役割

管理監督者は、本人の状態を診断する立場ではありません。業務内容や職場環境、復帰後の配慮事項を把握し、産業医・人事労務部門・主治医等との連携の中で復帰を支える役割を担います。

試験での注意点

本人の希望だけで復帰を決める、主治医の診断書だけで職場側の検討を省略する、復帰後のフォローアップを不要とする記述は注意が必要です。
