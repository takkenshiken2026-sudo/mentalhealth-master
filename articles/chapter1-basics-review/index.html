メンタルヘルス・マネジメント検定II種｜第1章・基礎・役割の総復習｜領域①と4つのケア

メンタルヘルス・マネジメント検定II種（ラインケア）の第1章·基礎·役割の総復習は、100問·7領域の領域①で法令·管理監督者の役割·4つのケアが四択で問われる論点の正本です。領域①の詳細論点はfield-law-basics記事、4ケア一覧はfour-types-careと役割分担します。たとえば6月6日時点·10月12日試験まで残り18週·6月第2週演習20問·第1章8問中4問正解（50％）なら、4つのケア表を確認してから6月第3週7日後に解き直す逆算が定番です。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の公式テキスト第1章です。

この記事の要点

本記事を読むと、たとえば演習20問·第1章8問中4問正解の場合に、領域①の法令·4つのケア·管理監督者役割の総復習表とfield-law-basics/four-types-careとの使い分けが分かり、70点合格の基礎得点源として整理できます。

1第1章·基礎·役割の総復習（領域①·100問·7領域）

II種ラインケアの第1章は領域①意義·法令·管理監督者の役割が中心です。100問·120分·70点以上·7領域の基礎得点源として優先度が高い章です。

| 論点 | 内容 | 頻度 |
| --- | --- | --- |
| 意義 | メンタルヘルス対策 | 高 |
| 法令 | 安全配慮義務 | 高 |
| 役割 | 管理監督者 | 高 |
| 4ケア | 全体像 | 高 |

  • たとえば6月第2週演習20問·第1章8問中4問正解（50％）なら
  • 6月第3週7日後に同8問を解き直し
  • 正答率70％以上を目指す流れが定番

I種105+論述25点の第1章論点と混同しないでください。

24つのケア総復習表（気づき·配慮·相談·改善）

4つのケアは第1章の中核論点です。four-types-care記事で詳細表を確認します。管理監督者の診断·個票開示は誤答です。

| ケア | 管理監督者 | 禁止 |
| --- | --- | --- |
| 気づき | 変化への注意 | 放置 |
| 安全配慮 | 業務調整 | 一律休職 |
| 相談対応 | 傾聴·紹介 | 診断代行 |
| 環境改善 | PDCA | 個人責任のみ |

  • 例えば6月第3週にfour-types-care記事を読み
  • 演習10問·4ケア5問中3問正解（60％）なら
  • 6月第4週7日後に同5問を解き直す流れが定番

3法令·管理監督者役割の要点表（安全配慮·主体分担）

第1章では安全配慮義務と管理監督者·事業者·産業医の主体分担が頻出です。field-law-basics記事で条文論点を確認します。

| 主体 | 義務·行為 | 禁止 |
| --- | --- | --- |
| 事業者 | 体制整備 | 個票開示 |
| 管理監督者 | 気づき·配慮 | 医学的診断 |
| 産業医 | 医学的判断 | 日常面談代行 |
| 労働者 | 相談 | 自己完結 |

たとえば7月第1週演習20問·主体分担6問中3問正解（50％）なら、7月第2週にfield-law-basics記事の主体表を暗記し同6問を解き直す流れが定番です。

4第1章頻出誤答表（診断代行·個票開示·主体混同）

第1章の頻出誤答は、管理監督者が診断する·ストレスチェック個票を上司に開示·事業者と管理監督者の役割混同が典型です。

| 誤答 | 正解 | 確認先 |
| --- | --- | --- |
| 上司が診断 | 傾聴·連携 | 本記事 |
| 個票開示 | 集団分析 | stress-check |
| 個人責任のみ | 組織的改善 | four-types-care |
| 放置 | 気づき·配慮 | line-care |

  • 例えば7月第2週演習30問·第1章12問中6問正解（50％）なら
  • 7月第3週に本記事の誤答表を暗記し
  • 同12問で正答率70％以上を目指す流れが定番

5field-law-basics/four-types-care/line-careとの連携

第1章総復習に関する記事は役割分担しています。

| 記事 | 役割 |
| --- | --- |
| chapter1-basics-review（本記事） | 第1章総復習·正本 |
| field-law-basics | 領域①詳細論点 |
| four-types-care | 4ケア一覧·中核 |
| line-care | ラインケア全体 |

  • たとえば6月第2週にfield-law-basicsで領域①表
  • 6月第3週にfour-types-careで4ケア表
  • 7月第1週に本記事で総復習誤答表を確認する流れが定番

III種の第1章論点と取り違えないでください。

6よくある質問

第1章は100問中どの程度出題されますか？
7領域均等に近い配分が原則で、第1章·領域①は基礎得点源として10〜15問程度が目安です。たとえば6月第2週演習100問中第1章12問·6問正解（50％）なら、6月第3週に本記事の4ケア表を暗記し、同12問7日後解き直しで9問正解（75％）を目指してください。100問120分·70点以上·7領域がII種の形式です。
4つのケアと管理監督者の役割はどう対応しますか？
4つのケアすべてに管理監督者の行動要素がありますが、医学的診断·治療判断は担いません。例えば7月第1週演習10問·「4ケア＝上司が診断」2問が誤答なら、7月第2週にfour-types-care記事の4ケア表を読み直し、同分野10問を解き直す流れが定番です。105点＋論述25点はI種の基準であり、II種70点とは異なります。
chapter1-basics-reviewとfield-law-basicsはどう使い分けますか？
chapter1-basics-review（本記事）は第1章·4ケア·主体分担の総復習·誤答表に特化、field-law-basicsは領域①の法令·条文論点の詳細が正本です。たとえば6月第2週にfield-law-basicsで領域①表、6月第3週に本記事で総復習誤答表を確認する順が定番です。70点の詳細はpass-scoreが正本です。
