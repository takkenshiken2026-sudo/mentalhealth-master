メンタルヘルス・マネジメント検定II種の試験日程・受験料・当日の持ち物

メンタルヘルス・マネジメント検定II種（ラインケア）の申込前は、試験日程·受験料·当日持ち物の3点を要項で一括確認するのが定番です。たとえば6月6日時点で10月12日（日）10:00開始まで残り18週なら、6月第1週に要項PDFで日程·受験料章·持ち物章を3点早見表にまとめ、100問·70点合格の学習を並行開始する逆算が定番です。本記事では3点早見表を掲載し、日程詳細はexam-schedule·受験料はexam-fees·持ち物はexam-day-itemsと役割分担します。正本は公益財団法人 日本産業衛生協会（https://www.mental-health.ne.jp/about/）の受験要項です。

この記事の要点

本記事を読むと、たとえば申込前に「日程はどこで確認·受験料はいくら·持ち物は何点」の3点を1本で把握でき、詳細確認先（exam-schedule/exam-fees/exam-day-items）の使い分けが分かります。

  • 3点早見表
  • 要項正本
  • 100問120分
  • schedule連携
  • fees·items分担

1試験日程·受験料·持ち物の3点早見表

II種ラインケアの申込前チェックは、日程·受験料·持ち物の3点に集約できます。いずれも公開試験 受験要項が正本です。

| 確認項目 | 正本 | 詳細記事 |
| --- | --- | --- |
| 試験日程 | 要項「日程」章 | exam-schedule |
| 受験料 | 要項「受験料」章 | exam-fees |
| 当日持ち物 | 要項·受験票 | exam-day-items |

  • たとえば6月第1週に要項PDFを開き
  • 3章を1枚の早見表に書き
  • 7月15日申込開始·10月12日試験日をカレンダー登録する流れが定番

I種105+論述25点·衛生管理者30問180点と混同しないでください。

2試験日程の確認ポイント（exam-schedule連携）

試験日·申込期間·合格発表は年度で変わるため、固定の月日表記は本文に載せず要項が正本です。

| 項目 | 確認 |
| --- | --- |
| 申込開始 | 要項PDF |
| 申込締切 | カレンダー登録 |
| 試験日 | 100問·120分·10:00開始目安 |
| 合格発表 | 要項記載 |
| 受験地 | 全国15都市·要項確認 |

  • 例えば7月15日申込開始·8月10日締切·10月12日試験なら
  • 6月第1週に本早見表を作成し
  • 日程の詳細·15都市リストはexam-schedule記事で深掘りする流れが定番

3受験料の確認ポイント（exam-fees連携）

受験料·支払方法·返金規定は要項の「受験料」章が正本です。本文に固定の円表記は載せません。

| 項目 | 確認 |
| --- | --- |
| 金額 | 要項PDF |
| 支払方法 | 申込画面 |
| 支払期限 | 締切3日前まで |
| 再受験 | 別申込·別受験料 |
| 返金 | 要項の例外規定 |

  • たとえば7月15日申込開始なら
  • 7月第1週に要項で金額をメモし
  • 8月7日までに決済完了·金額·返金の詳細はexam-fees記事で確認する流れが定番

4当日持ち物の確認ポイント（exam-day-items連携）

持ち物は受験要項·受験票が正本です。前日21:00までに7点をそろえるのが定番です。

| # | 品目 | 確認 |
| --- | --- | --- |
| 1 | 受験票 | 氏名·会場 |
| 2 | 身分証 | 申込表記一致 |
| 3 | 筆記用具 | 黒または青 |
| 4 | 非電子式時計 | 音なし |
| 5 | 飲み物 | 要項どおり |
| 6 | マスク等 | 要項確認 |
| 7 | スマホ | 電源OFF |

例えば10月11日21:00までに7点をカバンに入れ、詳細ルール·身分証表記はexam-day-itemsで最終照合する流れが定番です。100問120分·70点以上が本番の形式です。

53記事との役割分担早見表

日程·受験料·持ち物に関する記事は4本に役割分担しています。

| 記事 | 役割 |
| --- | --- |
| schedule（本記事） | 3点概観·早見表 |
| exam-schedule | 公開試験·15都市·要項 |
| exam-fees | 受験料·再受験·返金 |
| exam-day-items | 持ち物詳細·要項 |

たとえば6月第1週に本記事で3点早見表を作成、同日にexam-scheduleで要項PDFの日程表を印刷、7月第1週にexam-feesで受験料章·10月11日にexam-day-itemsで持ち物7点を最終確認する流れが定番です。

6よくある質問

試験日程·受験料·持ち物はどこで確認しますか？
いずれも公益財団法人 日本産業衛生協会の公開試験 受験要項が正本です。たとえば6月第1週に要項PDFを開き、日程·受験料·持ち物の3章を1枚の早見表に書く流れが定番です。詳細はexam-schedule（日程）·exam-fees（受験料）·exam-day-items（持ち物）の各記事で深掘りしてください。100問·四択一·120分·70点以上·7領域がII種の形式です。
scheduleとexam-scheduleはどう違いますか？
schedule（本記事）は日程·受験料·持ち物を3点早見表で1本概観する記事、exam-scheduleは公開試験·15都市·要項確認に特化しています。例えば申込前に本記事で3点を一覧確認し、日程の詳細·申込逆算はexam-schedule、受験料金額はexam-feesと併用する流れが定番です。III種の要項と取り違えないようII種章だけを参照してください。
持ち物はいつそろえればよいですか？
試験前日21:00までに持ち物7点をカバンに入れるのが定番です。たとえば10月12日（日）10:00開始なら、10月11日18:00に7点をテーブルに並べ、21:00にカバンへ入れ、詳細ルールはexam-day-itemsで最終照合してください。100問120分の本番は10:00開始·9:00会場到着が目安です。当日動線はexam-day-flowが正本です。
